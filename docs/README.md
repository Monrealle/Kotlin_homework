# Документация hw3

Диаграммы сделаны в PNG, чтобы архитектуру и поток выполнения можно было показать на ревью без открытия PlantUML.

## `architecture.png`

Показывает новую архитектуру hw3 после объединения hw2 и GUI из main:

- ConsoleApplication и Compose Desktop GUI как два входных слоя;
- общий `GuiController` и Application-слой;
- Domain-модели, сервисы и контракты репозиториев;
- in-memory реализации для консоли;
- JSON-реализации для GUI;
- три файла локального JSON-хранилища.

## `sequence.png`

Показывает два потока работы:

1. GUI: запуск → чтение JSON → создание партии → ручная расстановка → проверка → ходы → рейтинг → сохранение JSON → подробная история.
2. Консоль: команды → Application/Domain → сохранение в in-memory репозитории.

В GUI автоматическая расстановка показана как дополнительный вариант, а ручная расстановка — основной путь.

## Что зафиксировано в hw3

- одна общая бизнес-логика для GUI и консоли;
- GUI и консоль используют разные реализации одних и тех же repository interfaces;
- GUI сохраняет данные в JSON;
- консоль работает только in-memory;
- ручная расстановка является основной;
- автоматическая расстановка остаётся вспомогательной кнопкой;
- в истории доступны ходы, обе расстановки, результат и рейтинг;
- незавершённые партии после нового запуска GUI помечаются как `ABANDONED`;
- база данных hw4 по-прежнему не используется.
