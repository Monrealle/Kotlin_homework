# Десктоп приложение администрирования игры «Морской бой»

Объектно-ориентированное программирование, Технологии программирования,
Математико-механический факультет, СПбГУ.

## Что реализовано

- регистрация игроков и просмотр их статистики;
- создание партии между двумя реальными игроками;
- ручная расстановка кораблей в формате, совместимом с консольной версией;
- полная проверка флота, координат, пересечений и соприкосновений;
- дополнительная кнопка автоматической расстановки;
- ввод и проверка ходов;
- определение `MISS`, `HIT`, `SUNK`, `WIN`;
- подсчёт и сохранение рейтинга после победы;
- сохранение истории партий;
- просмотр всех ходов обеих сторон;
- просмотр расстановки кораблей обоих игроков;
- просмотр рейтингов до и после партии и изменения рейтинга;
- локальная статистика игроков;
- GUI на Compose Desktop;
- JSON persistence для GUI;
- in-memory persistence для консоли;
- unit, integration и system tests.

Бот в предметную область не добавлялся. Администратор работает только с двумя реальными игроками.

## Сборка

Используется Gradle Wrapper.

```bash
./gradlew clean build
```

## Запуск GUI

GUI является основной задачей Gradle `run`:

```bash
./gradlew run
```

При первом запуске создаются JSON-файлы:

```text
data/players.json
data/ratings.json
data/games.json
```

После перезапуска GUI сохранённые игроки, рейтинги и история партий загружаются обратно.

## Запуск консоли

Консоль запускается отдельной Gradle-задачей:

```bash
./gradlew console
```

Консоль использует только in-memory репозитории, поэтому её данные существуют только в рамках текущего запуска.

## Ручная расстановка кораблей

Основной способ в GUI — ручной ввод.

Пример:

```text
A1-A4; C1-C3; E1-E3; G1-G2; I1-I2; G4-G5; A7; C7; E7; G7
```

Правила:

- 1 линкор;
- 2 крейсера;
- 3 эсминца;
- 4 катера;
- только горизонтальные и вертикальные корабли;
- корабли не пересекаются;
- корабли не соприкасаются даже по диагонали.

Кнопка `Авторасстановка` является дополнительным способом для быстрого заполнения флота, но не заменяет ручную расстановку.

## История партии

После завершения партии в истории доступны подробности конкретной партии.
GUI использует тот же `GameHistoryFormatter`, что и консоль, поэтому отчёт содержит:

- игроков и статус;
- все ходы с номерами, игроками, координатами и результатами;
- полную расстановку кораблей первого игрока;
- полную расстановку кораблей второго игрока;
- победителя;
- рейтинг каждого игрока до и после партии;
- дельту рейтинга.

Эти данные сохраняются в `data/games.json` и доступны после следующего запуска GUI.
